# Storefront visual assets — provenance

Internal record of where the storefront's pictures come from. Not shown to customers.

## Summary

| Asset | Where | Kind | Source / author | Licence |

There are **no photographs** and **no files fetched from the internet**: nothing was downloaded, hotlinked,
copied from a competitor, or generated by an image model. All art is inline SVG in the source, so there are no
image files in `public/` and no external image requests from the storefront chrome.

## Rules these assets follow

- They are decorative **illustrations**, marked `aria-hidden`; the visible text carries the meaning. They are
  not photographs and must not be presented as such.
- They are **never used as the picture of a real product.** A real product shows only its own uploaded photo
  (served from object storage). With no photo it shows the plain "Photo not added yet" placeholder — never an
  illustration, stock image or generated image standing in for the item.
- Category tiles link only when a published product belongs to the category; otherwise the tile is muted and
  says "No products listed yet".
- The header and footer deliberately contain no `<img>` element: `tests/e2e/product-images.spec.ts` takes the
  first `<img>` on a product page and expects it to be the product photo.

## If real photography is wanted later

Real, licensed photography of taekwondo equipment would look better than these illustrations. If adopted:
record each file here (file name, original URL, photographer, licence name and URL, date retrieved, any
required attribution), store it under `public/` (no hotlinking), use it only for hero/category decoration (not
as a product photo), and re-check the licence permits commercial use. Prefer photographing the shop's own stock.
